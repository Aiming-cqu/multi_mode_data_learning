## 概述

建立 Human In Loop 测试框架，用于需要人工介入验证结果的测试场景（如 Excel 样式、图表视觉效果），以及需要人工提供输入的测试。

## 背景

Excel 导出功能（样式、图片嵌入、数据验证）等测试依赖视觉判断，自动验证成本过高或不可行，需要人工介入。

## 范围

**在范围内：**

- pytest -s 交互式测试支持
- 测试用例中的人工验证指导（print 提示）
- 覆盖 Excel 导出（样式、图片嵌入、数据验证）

**不在范围内：**

- 不自动执行这些测试（不加到 CI）
- 不替代自动化测试

## 成功指标

| 指标 | 基线 | 目标 | 评价方法 |
| ---- | ---- | ---- | -------- |
| HIL 测试覆盖 | 无 | ≥ 3 个 HIL 测试用例可用 | 人工执行验证 |
| 测试指导清晰度 | 无 | 非开发者可独立执行 | 找非项目成员测试 |
