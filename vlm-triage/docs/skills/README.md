## 如何编写 Skill

使用 [templates/skill-template.md](../templates/skill-template.md)，结构如下：

1. 名称和简介（Act 类 / Observe 类 / Plan 类）
2. 何时使用
3. 核心概念
4. 快速开始
5. 高级用法（含 DO/DON'T）
6. 最佳实践（含 DO/DON'T）
7. 故障排除
