## 三、每个层级负责什么

- **总导航**：告诉你在哪里、下一阶段在哪里。
- **00 规划**：解释为什么学、整体顺序是什么。
- **阶段 README**：说明本阶段目标、前置条件、要产出的文档及退出标准。
- **阶段笔记**：写自己的理解与代码、实验依据。
- **阶段 experiments/**：按需保存可复现配置、运行方式、小型统计；原始业务数据仍保留原位。
- **90 模板**：统一记录方式，不要求写长文章。

建了目录不等于开始学习，写了笔记不等于通过验收。01 已完成笔记与互动问答概念验收，但不把已有输出文件认定为已验证实验成果。

## 四、框架理解分三层

1. **01 宏观认知**：输入、配置、执行器、算子、输出分别做什么。
2. **03 框架调用链**：真实入口怎样驱动代码处理一条样本。
3. **06 规模化与执行机制**：有瓶颈证据后再理解并行、资源和失败处理。
