## 阶段定位

- **目标**：通过两次只改变一个尺寸阈值的实验，建立“先预测、再运行、后核对”的加工直觉。
- **建议时机**：入门第 1 周，宏观地图之后，以验收而非日历推进。
- **前置条件**：01 宏观认知已通过；能区分输入清单、配置、执行器、算子和输出。
- **当前状态**：已进入本阶段，实验已运行并与预测逐条核对，验收通过（2026-09-14）。

## 本阶段文档

- **唯一学习与执行入口：[02-尺寸过滤实验.md](02-尺寸过滤实验.md)。** 阅读材料、问题、预测、实验步骤、记录和验收全部在该文件中完成，不需要在两个文档间往返。
- 真正开始运行时再创建 `experiments/`，保存两份最小配置、运行说明和小型结果摘要。
- 输入复用 Data-Juicer 自带的 3 张测试图片；不搬动原图，不复制完整日志，不引入模型算子。

## 验收与退出

详细检查项在[实验笔记第 6 节](02-尺寸过滤实验.md#6-验收结果)。总体满足以下条件才进入 [03-框架调用链](../03-框架调用链/README.md)：

- 两份配置确实只有一个规则参数变化，并保留各自配置与命令。
- 预测表和实际输出可逐条对应，能解释至少 3 张图片为何保留或过滤。
- 干净输入下，`输入数 - 输出数 = 过滤数`；若不成立，先定位重复、异常或统计口径问题。
- 能区分“结果符合规则”和“有本轮执行证据”，并确认过滤清单没有删除或改写原始图片。

未满足时留在本阶段补证据，不扩大阅读范围。
